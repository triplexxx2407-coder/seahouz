# Sea Houz · Baja Ocean Residences (prototipo)

Prototipo en un solo archivo: `index.html`. Para verlo, descárgalo y haz doble clic (necesita internet para cargar Tailwind, Chart.js y las fuentes).

- **El Comprador**: quiz de 4 pasos y tarjeta con Código VIP de Acceso Directo de Dueño.
- **El Propietario**: dashboard en español con KPIs, gráficas, CRM de leads y AI & Data Insight.

Los leads que se capturan en el quiz aparecen al instante en el CRM del dashboard. Todos los datos son ficticios.

Para publicarlo gratis: Settings → Pages → Deploy from a branch → `main` / root.
